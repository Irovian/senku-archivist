# Activation of the Incident Command System

## Purpose
This document explains how {{facility_name}} activates the Incident Command System during an all-hazards response and establishes command locations, initial command responsibilities, and all-clear communication.

## Activation Relationship
The Incident Command System may be activated when the Emergency Operations Plan is activated or when an incident requires organized leadership, defined roles, coordinated communication, and documented response priorities. Activation may be full or partial depending on the event.

This all-hazards document covers the immediate activation step from Section B. It does not replace the separate Section C Incident Command System documents, which contain the command organization, job action sheets, forms, and role-specific instructions.

## Command Center Activation
When incident command is activated, the person in charge should identify the command location, notify designated leadership, and begin coordinating the response from the selected command center or alternate communication structure.

The primary command center location is {{primary_command_center_location}}. The alternate command center location is {{alternate_command_center_location}}. These locations should be accessible to leadership, support response communication, and remain flexible if the incident makes the primary location unsafe or unusable.

Leadership should notify facility leaders and command center personnel using {{emergency_code_alert}} or another approved activation phrase when a different code word is needed: {{code_word_different_than_indicated}}.

## Initial Command Actions
The Incident Commander or activating leader should establish immediate response priorities, assign command functions as needed, request department status reports, determine whether outside support is needed, and document significant decisions. Initial priorities should focus on resident safety, staff accountability, building conditions, hazard control, communication capability, supplies, staffing, and whether residents can remain safely in place.

Command activation should be scaled to the event. A limited incident may require only leadership coordination and documentation. A larger event may require formal command roles, a command center, action planning, operational periods, resource tracking, and coordination with emergency management or response agencies.

## All-Clear and Deactivation
When the Incident Commander determines that the activation can end or scale down, leadership should communicate the all-clear or deactivation message through the approved staff alert method. The all-clear should identify whether normal operations resume immediately, whether recovery work continues, and whether any departments must keep modified procedures in place.

After deactivation, response documentation, open issues, resident or operational impacts, and needed plan updates should move into the facility's recovery and after-action process.

## What Staff Should Understand
- Incident command activation organizes leadership, communication, documentation, and response priorities.
- The primary and alternate command center locations must be known before an emergency occurs.
- This all-hazards topic covers immediate activation; Section C owns detailed incident command roles and job action sheets.
- Activation can be scaled to match the incident.
- The all-clear or deactivation message should be issued only by the Incident Commander or designated leader.
