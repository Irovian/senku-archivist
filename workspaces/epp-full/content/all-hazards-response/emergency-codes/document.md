# Emergency Codes

## Purpose
This document explains how {{facility_name}} maintains emergency codes or plain-language alerts so staff can recognize emergency conditions and begin the correct response quickly.

## Code System
Emergency codes are used to alert staff that an emergency condition exists, that leadership or specific response roles should report, or that staff should begin protective actions. The facility's all-hazards activation code is {{emergency_code_alert}}.

The emergency code list should match the facility's actual procedures, terminology, and staff training materials. Review and update the code list or plain-language wording here: {{this_common_code_words_match_procedures}}.

Some organizations use traditional color codes, some use plain-language alerts, and some use both. Whatever system is selected, the wording should be clear enough that staff know what happened, where to report, what protective action to start, and whether residents or visitors need immediate direction.

## Alert Methods
Emergency codes or alerts may be communicated by overhead announcement, paging system, telephone, portable radio, pager, runner, fire alarm interface, electronic notification system, or another method approved by the facility. The selected staff alert method should be documented here: {{indicate_method_means_used_alert_staff}}.

The alert method should account for routine hours, after-hours operations, power or communication disruptions, noisy work areas, staff who are away from nursing units, and the need to avoid unnecessary public confusion when a discreet notification is safer.

## Maintaining Code Readiness
The facility should keep emergency code language consistent across the emergency plan, incident-specific procedures, staff education, drills, communication tools, and posted or quick-reference resources. When the facility changes a code word, plain-language phrase, announcement process, or alert method, related training and response documents should be updated together.

Emergency codes do not replace procedure-level instructions. They start the response and direct staff toward the right plan, role, location, or protective action.

## Coordination With Related Documents
This topic should be read with:

- Activation of Emergency Operations Plan (EOP), which explains when the all-hazards response is activated.
- Activation of the Incident Command System, which explains command center activation and all-clear coordination.
- Hazard-specific procedures, which identify event-specific protective actions.
- Communications and emergency contact documents, which maintain communication expectations and contact information.

## What Staff Should Understand
- Emergency codes or plain-language alerts are used to start the correct response quickly.
- Staff should know the facility's all-hazards activation alert and the alert methods used during different conditions.
- Code language must match the facility's actual procedures and training.
- An emergency code tells staff that action is needed; the related procedure explains the detailed response.
- Alert methods should work during normal operations and during communication or utility disruptions.
